# Семинары курса Дискретная математика в РЭУ им. Г.В. Плеханова

В этом репозитории хранятся материалы семинаров по дискретной математике ПМИ, РЭУ им. Г.В. Плеханова. Репозиторий содержит конспекты семинаров (условия задач и заметки решений) и домашние задания с ответами для самопроверки.    

## Летопись курса

1. Неделя 1: 06.10.2026 (2 пары)  
**Темы**: метод математической индукции, системы счисления.                          

2. Неделя 2: 09.10.2026 (1 пара), 13.10.2026 (1 пара)  
**Темы**: наивная теория множеств, отношения и отображения.

3. Неделя 3: 13.10.2026 (1 пара), 16.10.2026 (1 пара)  
**Темы**: принцип Дирихле, подсчет числа сочетаний и размещений, базовые принципы комбинаторики: умножения, сложения, включений и исключений.

4. Неделя 4: 23.10.2026 (2 пары)   
**Темы**: свойства биномиальных коэффициентов, упоминание чисел Стирлинга.
